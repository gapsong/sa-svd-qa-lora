# Run note: 2026-06-03, first full measured reproduction

SmolLM2-1.7B, 2-bit GPTQ, QA-LoRA fine-tune. rank=16, group_size=16, lr 1e-4,
dropout 0.0, global batch 16, 750 steps, seed 0. Stack: the pinned versions in
`requirements.txt` (stock gptqmodel 6.0.3, upstream peft 0.19.1, torch 2.12).

| Method                | WikiText-2 PPL |
|-----------------------|----------------|
| QA-LoRA (random init) | 42.45          |
| SA-SVD (ours)         | 36.02          |

## Findings

1. No collapse: the baseline landed at 42.45, not the ~172 of the thesis.
   Modern stock gptqmodel quantizes SmolLM2 at 2-bit well enough that
   random-init QA-LoRA trains to a semi-usable model. The failure mode the
   thesis narrative is built on does not occur on this stack.
2. SA-SVD still wins: 36.02 vs 42.45, a ~15% perplexity reduction at strictly
   identical training budget, rank, group size, and seed. It won despite
   starting worse: its init-only PPL was ~25.8k vs the baseline's ~12.2k. The
   advantage is not "starts closer to the solution"; the principal-component
   structure in the adapter gives optimization a better direction even from a
   worse starting point.

Honest one-liner for this stack: quantization did not collapse, and SA-SVD
still improved final perplexity by ~15% for free.

## Caveats

- One seed, one run each. The 6-point PPL gap is probably real, but quote a
  percentage only after 2-3 seeds.
- Minor confound: the sa_svd run used per-device batch 2 x grad-accum 8
  (baseline: 4 x 4) due to GPU sharing during the run. Same effective global
  batch of 16, so footnote-level.
- Neither method crosses the ~30 "usable" threshold, so "SA-SVD makes a usable
  model where the baseline is broken" is not supported here. The supported
  claim is "SA-SVD is a consistently better init".

## Open question and next step

Whether the dramatic 172 -> 26 repair shows up on the collapse-prone
thesis-era quantizer (`gapsong/GPTQModel@qzero_unquantized` fork) remains
untested. Next step for the repo: apply the same baseline-vs-SA-SVD comparison
to other models (e.g. Qwen2-1.5B at lr 3e-5, TinyLlama-1.1B) to map where the
initialization helps.

# Multi-model sweep (same day, 2026-06-03)

Same config per model: rank=16, group_size=16, dropout 0.0, global batch 16,
750 steps, seed 0, WikiText-2 eval. LR per model: 1e-4 default, 3e-5 for Qwen2
(thesis Table 4.1). Qwen2 ran at per-device batch 2 x grad-accum 8 (its 151k
vocabulary OOMs a 24 GB card at per-device batch 4); TinyLlama at 4 x 4.

| Model          | baseline | sa_svd | delta |
|----------------|----------|--------|-------|
| SmolLM2-1.7B   | 42.45    | 36.02  | -15%  |
| TinyLlama-1.1B | 34.63    | 28.68  | -17%  |
| Qwen2-1.5B     | 53.15    | 27.61  | -48%  |

## Findings

1. SA-SVD improved every model tested, and pushed TinyLlama and Qwen2 below
   the ~30 "usable" threshold.
2. Qwen2 is the qualitative outlier: the random-init baseline DID NOT TRAIN.
   grad_norm was inf at every logged step in two independent runs (the first
   at batch 4, the second at batch 2), loss pinned at ~5.7-6.0, token accuracy
   ~17%. Its 53.15 is effectively the PPL of the unadapted quantized model.
   The 2-bit base itself is healthy (forward pass fine); the failure is
   gradient overflow in the backward pass. With SA-SVD init the same setup
   trains normally (grad_norm 15 -> 9, loss 2.3 -> 1.9), reaching 27.61.
   So on Qwen2 the comparison is not "better vs worse" but "trains vs does
   not train".

## Methodology notes (apply to all runs equally)

- The sliding-window eval in `pipeline.py::evaluate_wikitext` scores every
  token of each 1024-window (the `-100` masking line is a no-op because
  trg_len equals the window length). Overlap tokens are scored twice, once
  with short context, so absolute PPLs are somewhat pessimistic vs the
  canonical HF stride recipe. Identical for all methods and models, so
  comparisons hold. Fixing it requires re-running everything (trained models
  are not saved); recorded as a follow-up.
- GPTQ calibration is 128 short WikiText-train snippets (avg ~116 tokens);
  gptqmodel recommends >=256 samples of >=256 tokens. Same for all runs.
- Single seed throughout.

# Update 2026-06-05: partially superseded

The single-seed findings above were stress-tested in a 12-run seed sweep and
a four-arm initialization ablation; see `results/ablation-2026-06-05.md`.
Two corrections to this note:

1. Finding 2's mechanism claim ("the principal-component structure in the
   adapter gives optimization a better direction even from a worse starting
   point") is retired. The measured decomposition: the singular values carry
   a consistent paired gain, the singular vectors provide seed-to-seed
   reliability, and the init-only PPL comparison is not load-bearing.
2. The SmolLM2 percentages should be quoted from the 3-seed sweep (mean -13%,
   9/9 pairings won, ~10x spread reduction), not from the single seed-0 pair
   above: the baseline's seed spread (4.2 PPL) is two-thirds of the seed-0
   gap.
